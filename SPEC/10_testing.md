# 10. テスト仕様

対象: テストのカテゴリと必須対象。スナップショットを行動テストの代替にしない。

---

## 1. 単体テスト

- パス正規化とワークスペース境界検証
- バッファ編集(挿入・削除・置換)、Undo / Redo、選択範囲
- grapheme・表示列計算(Unicode)
- 改行コード・末尾改行・BOMの保持
- Git porcelain出力のパース、diff / ハンクのパース
- 診断の正規化・重複排除・世代管理
- LSPメッセージのframing、UTF-16⇔内部表現の位置変換
- ルートマーカー検出
- キーバインド解決(キー→コマンドID)
- 設定のマージとフォールバック
- 外部変更競合の判定(ケースA/B/C/D)
- ファイルツリーのソート・遅延展開
- テーマの256色近似とフォールバック

## 2. 統合テスト

- ファイルを開く→編集→保存(置換書き込みの検証を含む)
- 一時Gitリポジトリでのstatus / diff / stage / unstage / restore / commit / branch
- リモート付き一時リポジトリ(ローカルbare)でのpush / pull / fetch
- ファイル監視: 作成・更新・削除・改名の反映
- 外部更新と未保存バッファの競合(データを失わないことの検証)
- PTYシェルの起動・入出力・リサイズ・終了、フルスクリーンTUIの起動
- モックLSPサーバーとのライフサイクル(initialize〜exit)、診断受信、hover / definition / completion
- コンパイラ出力(cargo JSON)からの診断生成
- セッション保存と復旧、異常終了検出
- 大きな検索結果の逐次処理とキャンセル
- 読み取り専用ファイル、シンボリックリンク、日本語ファイル名

## 3. スナップショット(描画)テスト

安定したUIコンポーネントに限定して使用する。

- ファイルツリー(Git状態・診断バッジ付き)
- Source Controlビュー、差分表示
- Problemsパネル
- エディタガター(行番号・差分・診断マーカー)
- コマンドパレット、ダイアログ
- ステータスバー
- フォーカスのアクティブ / 非アクティブ状態
- 小さい端末サイズ(80x24)
- 256色フォールバック、アイコンモード(ascii / unicode)

## 4. Unicode必須テストデータ

- 日本語(かな・漢字混在、長い行)
- 絵文字(ZWJシーケンス、Variation Selector)
- 結合文字、ゼロ幅文字
- 全角記号、East Asian Ambiguous文字
- タブ、CRLF
- 長い日本語ファイル名、正規化形(NFC/NFD)が異なるファイル名

## 5. 性能テスト(ベンチマーク)

- 1MB / 10MB / 100MBファイルのオープンと編集
- 1万 / 10万ファイルのワークスペースのツリー表示と検索
- 大規模Git差分
- 連続キー入力のレイテンシ
- 高頻度ファイル監視イベント(デバウンス検証)
- ファジー検索・全文検索のスループット
- 大量PTY出力時のUI応答性

CIでは絶対時間ではなく回帰率で判定する([09_quality.md](09_quality.md))。
